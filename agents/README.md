# Agents

This folder contains the agents used by Study Squad AI.

## Coordinator Agent

Receives user requests, determines which agents should be activated, and coordinates communication between agents.

## Tutor Agent

Generates quizzes and evaluates student responses using reusable Agent Skills.

## Coach Agent

Analyzes quiz performance, identifies knowledge gaps, and provides personalized learning recommendations.

## Resource Agent

Retrieves educational resources and learning materials using tools exposed through MCP servers.

These agents are orchestrated using Google ADK and work together to provide a personalized learning experience.
