# MCP Servers

This folder contains the Model Context Protocol (MCP) servers used by Study Squad AI.

MCP servers provide external capabilities that can be accessed by agents through a standardized interface. The use of MCP helps separate agent reasoning from tool execution and promotes a modular system architecture.

## Resource MCP Server

Provides educational resource retrieval tools, including topic-specific learning recommendations and educational video search.

Example capabilities include:

- Retrieving learning resources for a given topic
- Recommending educational videos
- Supporting subject-specific resource discovery

## Memory MCP Server

Provides study session storage and retrieval tools, including quiz history, performance tracking, and identified knowledge gaps.

Example capabilities include:

- Saving quiz results
- Retrieving previous study sessions
- Tracking student performance over time
- Storing identified knowledge gaps
