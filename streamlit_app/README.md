# Streamlit Application

This folder contains the Streamlit user interface for Study Squad AI. This application serves as the primary entry point for users and enables interaction with the multi-agent learning assistant. In other words, the Streamlit application allows users to:



* select a subject, topic, and difficulty,
* generate and complete quizzes,
* receive AI-generated coaching feedback,
* view recommended learning resources, and
* review previous quiz attempts through the Quiz History page.
